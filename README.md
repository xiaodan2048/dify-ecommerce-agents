# 电商场景 AI Agent 三件套 · Dify 复刻

用 [Dify](https://dify.ai) 搭的三个电商运营场景 Agent 演示：**售后 Agent**、**经营周报 Agent**、**内容生产 Agent**。
每个都附带完整的代码节点、提示词、演示数据、评测集和逐步搭建指南，零代码基础也能照着复刻。

> 所有品牌（清屿、元养）、店铺、买家、订单、经营数据、快递公司、地址和商品资料都是**虚构的演示数据**，与任何真实公司无关。

## 三个 Agent 一览

| | 售后 Agent | 经营周报 Agent | 内容生产 Agent |
|---|---|---|---|
| 目录 | [`售后Agent_Dify复刻包/`](售后Agent_Dify复刻包/) | [`周报Agent_Dify复刻包/`](周报Agent_Dify复刻包/) | [`内容Agent_Dify复刻包/`](内容Agent_Dify复刻包/) |
| Dify 应用类型 | Chatflow | 工作流 | 工作流（另附一个合规评测工作流） |
| 做什么 | 回答买家的物流、改地址、退换货、投诉问题，按品牌政策判定能否退换 | 发现店铺经营异动、自动归因，生成异动提醒和周报 | 从商品参数和买家评价提炼卖点，按平台写种草内容，并过合规审核 |
| 核心设计 | 能画出流程图的走固定流程，只有退换货判定交给 Agent 自主调工具 | 规则判异动，代码算数字，模型只讲原因，代码再查依据 | 3 个 Agent 固定编排；卖点可溯源；规则初检 + 模型语义审核 + 终稿复检 |
| 安全护栏 | 订单身份校验、写操作需买家确认、输出越权检测 | 账号级店铺权限、9 个预定义查询模板（不写 SQL）、防"穿越"回测 | 功效白名单、极限词/医疗用语规则库、终稿规则复检 |
| 评测 | 50 条分层评测集（任务完成率、工具调用正确率、越权率） | 21 个历史异动回测 + 12 条功能用例（主因一致率、依据校验通过率） | 48 条合规样本 + 15 条生成用例 + 11 条功能用例 |

## 每个文件夹里有什么

```
xxxAgent_Dify复刻包/
├── README_搭建指南.md   从零搭建的步骤、每个节点为什么这样设计、常见问题
├── dify代码节点/        Dify「代码执行」节点和工具用的 Python 代码，直接复制粘贴
├── 提示词/              LLM / Agent 节点的系统提示词和指令
├── 数据/                虚构的订单、政策、经营数据（内容 Agent 的数据在代码节点里）
└── 评测/                评测集 Excel（含标注口径、汇总公式和版本记录）
```

内容 Agent 还附带了 Dify DSL 文件（`内容Agent-演示.yml`、`合规关卡-评测.yml`），可在 Dify「导入 DSL 文件」一键复刻，以及一份节点图解网页（`内容Agent节点图解.html`）。

## 快速开始

1. 注册 [Dify 云版](https://cloud.dify.ai)，在「模型供应商」里配置一个支持 Function Calling 的模型（演示用的是 DeepSeek `deepseek-v4-flash`）。
2. 安装插件 **Dify Agent Strategies**（提供 FunctionCalling / ReAct 策略）。
3. 从任意一个文件夹的 `README_搭建指南.md` 开始，按步骤搭建、跑通、再用评测集回归。

演示环境的"当前时间"在代码里是固定的，所以每次运行结果可复现，评测结果也稳定。
